``get_publication_date`` prefers a valid online date, then a valid print date.
It preserves the reported year/month/day precision and returns ``unknown``
when neither date is available. A licence start date is not a publication
date, as distinguished in `Crossref's metadata documentation
<https://www.crossref.org/documentation/retrieve-metadata/rest-api/rest-api-filters/>`_.
Created, deposited and indexed dates are also not substituted. This lookup does
not change assigned release IDs or years. See ``examples/publication_metadata.py``
for a command-line example. Network lookup requires ``requests``.
