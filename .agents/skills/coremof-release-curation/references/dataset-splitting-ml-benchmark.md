# Portable ML benchmark contract

The complete portable contract is maintained in the parent `SKILL.md` and the
repository-root `ML_BENCHMARK_HANDOFF.md`. Read both completely. The latter is
the user-facing command, data-layout, target-free assignment, deferred-target,
checksum, and restricted-transfer guide. Do not substitute an original-host
curation runbook or infer release-production state on the GPU machine.

For combined target construction and the audited as-of-cutoff coverage, also
read repository-root `COMBINED_TARGET_DATASET.md`. Treat completion-only target
counts as source contributions, never as total availability. Preserve explicit
scientific nulls and attach targets only after the assignment digest is frozen.
